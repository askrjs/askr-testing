## Limits that remain visible

- Injection opens no sockets. Node adapter parsing, disconnects, backpressure, timeouts and network
  timing require actual transport tests. Browser rendering/focus/keyboard require browser tests.
- Native request cloning retains tee branches for caller reuse and redirect replay. Unbounded uploads
  and memory/backpressure qualification are outside this bounded-body matrix.
- An abort cannot stop arbitrary application work or undo a custom store write already started. That
  write can finish later; no subsequent cookie write begins. Wait for owned operations before clear.
- Shared stores have no transaction isolation. The executed arrival-order case uses the in-memory
  jar; an external store determines the ordering and durability of its own pending writes.
- SameSite navigation, browser credentials/CORS policies and browser networking are not emulated.
  The Node 24 native getSetCookie path is exercised; the legacy Headers fallback is partial coverage.
- API issue #45 remains open until the full coordinated candidate graph and generated website pass.
